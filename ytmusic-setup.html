Connect YouTube Music

YouTube doesn’t offer a public “now playing” API. This uses your logged-in music.youtube.com session (cookie) so the site can read your play history and sync lyrics.

  1. Open music.youtube.com and make sure you’re logged in.
  2. Press F12 → Network.
  3. Click around once (e.g. Library), then filter for browse.
  4. Click a browse request → Headers → find Cookie.
  5. Right-click the Cookie value → Copy, paste it below.

Checking…

After connecting, run the site with npm run server and open the homepage. Play a song on YouTube Music — the page should switch from your MP3 to live lyrics.
